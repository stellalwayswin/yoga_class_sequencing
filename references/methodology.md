# 瑜伽课程编排方法论

适用普通成人居家跟练。来源编号见 [sources.md](sources.md)。项目规则属于操作性设计判断，不是 NHS 瑜伽处方。

## 二、编排的决策顺序

学习者 → 具体目标 → 动作功能 → 实际练习量 → 顺序与衔接 → 教学与呼吸 → 素材剪辑 → 跟练验收。

不能倒过来先挑几段视频，再用重复和延长画面凑时长。

### 1. 先定义学习者

每节课记录：

- 经验：是否做过基础体式，是否能跟随口令独立调整。
- 功能：能否舒适盘坐、跪姿承重、上下地面、单腿短暂支撑。
- 设备：瑜伽垫、椅子、墙面、毛巾等是否可用。
- 当前限制：已知不适、伤病、特殊人群需求。普通课程不自动承担治疗性目标；明显超出一般课程范围时另行评估。
- 使用情境：首次学习，还是已学会动作后的重复训练。

依据：S4、S6、S7。项目规则：信息不足时明确“普通成人一般练习”的假设，并提供动作级简化方式；不能只写一句“量力而行”。

### 2. 把目标改写为可观察的训练任务

| 用户目标 | 本课程需要做的事 | 验收时看什么 |
|---|---|---|
| 减脂 | 增加可持续活动量，结合合适的力量练习 | 实际活动时间、可完成性、是否能持续练习；不猜热量 |
| 瘦下肢 | 将内容重点放在腿臀力量、控制与活动度 | 下肢动作是否有功能差异；不是反复堆叠同类屈膝姿势 |
| 全身 | 提供多个身体区域的有意义参与 | 肩臂、躯干、髋腿各自的作用是否清楚；不把抬手等同于充分上肢力量训练 |
| 体态改善 | 练习活动度、稳定控制和姿势觉察 | 是否既能活动又能控制；能否迁移到舒适坐、站和抬臂 |
| 放松 | 降低任务复杂度，安排舒适姿势和自然呼吸 | 是否出现新的高负荷或需要反复看屏幕的任务 |

来源支持：S1—S3、S5、S7—S9。表中具体课程验收方式属于项目规则。体态课不能把“所有人必须维持一个固定姿势”当作成功标准，也不能凭外观诊断体态问题。

### 3. 建立能用于编排的动作标签

现有动作名称、体式分类和链接只能用于检索。尤其已有分类存在与画面不一致的情况，需以实际示范复核。

每个入选动作至少补充以下字段：

| 字段 | 记录要求 |
|---|---|
| 动作身份 | 原始ID、名称、来源链接、素材版本 |
| 功能 | 力量／活动度／平衡／姿势觉察／恢复，可多选但需主次 |
| 运动特点 | 动态或静态；主要关节动作；主要支撑部位 |
| 前提 | 需要的活动范围、平衡能力、承重能力 |
| 开始与结束 | 站／坐／跪／俯卧／仰卧；朝向、脚位、左右侧 |
| 简化方式 | 可直接执行的减难版本；画面是否支持该版本 |
| 素材时间点 | 讲解、进入、实际保持或重复、退出、片尾的起止时间 |
| 口令 | 源音轨语言、关键指令、呼吸提示、下一动作预告 |
| 核验状态 | 已完整查看／仅抽帧／待核验；无法确认的字段留空 |

项目规则：没有完成上述核验的动作，不依赖名称直接编入正式课程。某动作有“简易”二字，也不自动判为初级。

### 4. 难度由任务要求决定

项目规则：分别判断动作复杂度、支撑稳定性、活动范围、连续负荷、恢复机会和教学需求，不合成未经验证的分数。

- 初级：动作容易理解；支撑稳定；幅度可调整；有明确示范、换姿和退出提示。初级不等于“短”，30分钟也可以初级。
- 中级：已掌握基础动作后，在保持控制的条件下增加某项挑战，例如持续时间、控制要求或训练密度。中级不等于“长”，也不等于三轮。
- 进阶时先改变一个主要变量，观察动作质量与恢复，再决定是否继续增加。
- 出现屏息、明显失衡、无法受控退出或疼痛，不以完成计时为优先。

这些是操作性分级，来源并未提供统一的瑜伽初中级标准。原课程的难度标签需要跟练验证。

### 5. 先计算练习量，再计算视频总长

每段分别记录：讲解、进入、动态重复、静态保持、退出、换姿、恢复。

总视频时间 = 所有时间段的并集。若口令与练习同时进行，不能重复相加。

动态动作记录完整且受控的重复次数；静态体式记录实际保持秒数；呼吸数可以作为跟练提示，但不能假定每个人一口气长度相同。

项目规则：

- 左右比较实际保持、次数、幅度及版本，不比较原视频总长。
- 动作库片段持续40秒，不代表40秒都在发力。
- 循环播放完整教学，会重复讲解与进入过程；不能把播放次数当作有效组数。
- 肌力、柔韧性与有氧时间分别描述。没有强度证据时不把整节瑜伽计作中等强度有氧。
- 不将S1的一般抗阻重复次数、接近疲劳的描述，机械套入所有静态瑜伽或零基础跟练。

“实际练习量”在本项目指已计量的动作时间或次数，不是保证产生效果的生理阈值。

### 6. 课程结构服务于动作需求

采用五段结构：进入与呼吸觉察 → 针对性热身 → 主练习 → 逐步回落 → 放松与结束。

项目规则：热身应准备本课真正需要的部位和支撑方式。例如，后续有跪姿承重时需考虑肩腕与四点支撑的准备；下肢重点课不能只用抬臂侧弯替代全部腿部准备。仅凭S6存在热身视频，不能宣称某个热身时长已经充分。

以下是排课预算示例，含各阶段内的教学、转换和休息，仅用于起草：

| 总时长 | 进入与热身 | 主练习 | 回落与结束 |
|---|---:|---:|---:|
| 10分钟 | 2分钟 | 6分钟 | 2分钟 |
| 20分钟 | 3分钟 | 14分钟 | 3分钟 |
| 30分钟 | 5分钟 | 20分钟 | 5分钟 |

它不是NHS建议或固定标准。若动作无法在预算内清楚教会，减少动作或降低复杂度，不压缩必要教学和转换；也不为了整分钟强行增加重复。

### 7. 把每一次衔接作为需要设计的动作

项目规则：先核对A动作的实际结束姿势，再核对B的实际开始姿势，然后检查支撑、朝向、左右、重心和所需时间。

- 同为站姿，不代表脚位相容；同为跪姿，也可能需要调整方向。
- 过渡库提供候选关系，不替代实际画面检查。
- 需要回正、收脚、转身、坐下或翻身的步骤应明确出现；预告在转换之前给出。
- 体位相近可减少不必要转换，但不是必须遵循“站→跪→卧”的唯一顺序。
- 换侧需要兼顾退出和重心重置，不只是黑屏显示倒计时。
- 不能以“做相反方向抵消前一个动作”代替负荷分析。

建议建立衔接记录：前动作结束时间点、后动作开始时间点、桥接步骤、口令、预算秒数、验证结果。

### 8. 把呼吸和教学写进课程脚本

S8明确强调流瑜伽的呼吸—动作连接；以下制作规则为本项目制定：

- 每个动作脚本回答：怎样进入、主要关注什么、怎样呼吸、如何减难、怎样退出。
- 首轮充分教学，后续轮以简洁提醒为主；需要另外可用的练习片段或新口令，不能随意切断源音频。
- 默认自然、连续、不过度用力的呼吸；不为了同步画面强迫延长呼吸或屏息。
- 吸呼配合需针对具体动作核验，不机械地把所有上举都规定为吸气。
- 同一时间只突出少量关键提示。需要侧身或闭眼练习时，不能完全依赖屏幕文字指导。
- 没有逐次核对呼吸与衔接的课程，标为分段跟练，不标为已验证的流瑜伽。

### 9. 针对三类目标的选课规则

减脂支持课：优先可持续完成、主要肌群参与和动作质量；不要以出汗多少或宣传词判断强度。若主练习以静态保持和讲解为主，应描述为力量／活动练习。依据S1—S3。

下肢重点课（项目规则）：检查屈膝、髋伸、侧向稳定、踝足控制等功能是否过度偏向某一类；无需每节全部覆盖，但每个重复动作应有理由。加入同类体式前，先检查已有动作的累计局部负荷。

全身体态课（项目规则）：从具体任务切入，例如舒适抬臂、躯干转动、髋部折叠或稳定支撑；把可控活动与稳定练习结合。不能仅靠长时间拉伸、固定收腹夹背或“纠正外观”定义效果。

### 10. 课后渐进与反馈

依据S2的可持续原则，项目规则要求记录：是否完成、主观难度、哪个转换来不及、哪个动作需要简化、是否出现不适。只有已有版本能较稳定完成，才增加一个训练变量。

同一节课可以保留“学习模式”和“练习模式”：前者教学更多，后者减少重复讲解，但两者都保留必要提示。不能把教学缩短后释放出来的所有时间自动填成更大负荷。

## 三、交付前的验收门槛

以下为项目自定门槛，未满足就记录为待修订，不用总分掩盖具体问题：

1. 人群与目标明确；没有无法证明的减脂或治疗承诺。
2. 每个动作已核验实际示范、起止姿势与关键时间点。
3. 每个主练习都说得清为什么选它、做多少、怎样减难。
4. 左右实际负荷已核对；差异有具体理由。
5. 每次转换都能在口令与预算时间内完成。
6. 初级／中级标签有任务要求与跟练表现依据。
7. 重要指令不互相冲突，不在剪辑处截断；必要时有听觉提示。
8. 总时长准确，但讲解、转换、恢复没有被误算为实际训练。
9. 视频解码、音画同步、字幕可读性、章节跳转分别检查。
10. 完整跟练验证与技术播放验证分别记录；后者不能代替前者。

完整跟练验证应由目标水平的真人完成，涉及不确定的动作适配与负荷时，由有资质的瑜伽教师／相关专业人员复核。模型的文案审阅和抽帧不能冒充真人体验或临床验证。
